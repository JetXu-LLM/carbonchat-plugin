name: open-carbonchat-community
description: Open the CarbonChat Community room when the user explicitly asks to open or launch CarbonChat Community or The Lobby.
---

Use this skill for an explicit open request. Clarify an ambiguous ‘Community’ once. If setup already owns this request, let it finish the same open attempt.

Follow the single [installation and opening procedure](../../INSTALLER.md).
Its public entry is https://carbonchat.codexforwork.com/install.md.
Reuse this request's installation, discovery, update and authentication results;
do not start a second procedure or duplicate an open attempt.

Opening authorizes no post, reaction, draft, publication or transfer of room
content into the Agent chat. Let the user handle credentials and access prompts.
Report installation, tool availability, open acceptance and visibility separately.
